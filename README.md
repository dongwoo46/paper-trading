# Paper Trading

모의투자 위에서 내 전략과 AI 의 판단을 검증하는 개인용 투자 실험실입니다.

이 시스템의 본질은 **투자 상태(주문·체결·잔고·포지션·손익)를 일관되게 유지하는 것**입니다. 기능이 많아도 이 상태가 흔들리면 전략 검증도, AI 실험도 의미가 없습니다.

## 무엇을 할 수 있나

| 가치 | 하는 일 |
|---|---|
| 모의투자 | 가상 계좌로 시장가·지정가 주문을 내고 체결·잔고·손익을 확인합니다 |
| 내 전략 테스트 | 규칙(이동평균 돌파, 손절·익절 등)을 전략으로 등록해 과거(백테스트)와 현재(모의 운영)에서 돌립니다 |
| «이때 샀으면» | 종목·과거 날짜·금액을 넣어 지금까지의 손익을 계산합니다 |
| 위험 성향 기반 운용 | 공격적·방어적 성향에 따라 자동매매의 포지션 크기를 정합니다 (설계 중) |
| AI 끼리 투자 | MiroFish 로 주제를 주고 여러 AI 가 모의투자한 결과를 비교합니다 |
| 정보 → 투자 계획 | 뉴스·공시·수급·차트 분석을 모아 저장하고, 관심 종목·섹터를 기준으로 투자 계획과 전략을 세웁니다 |

## AI 원칙

- AI 는 주문을 직접 실행하지 않습니다. 전략 후보와 근거만 제안합니다.
- 사람이 승인한 전략만 실시간 운영 대상이 됩니다.
- 전략의 생성·수정·평가·승인 이력은 버전으로 남깁니다.

## 도메인

| 도메인 | 핵심 기능 |
|---|---|
| 투자 실행 | 주문, 체결(부분 체결 포함), 취소, 포지션·평균단가, 예수금·홀드/해제, 브로커 연동(KIS·토스)과 원장 대사(reconcile) |
| 시장 데이터 | 실시간 시세(KIS·Upbit), 일봉·주봉(pykrx·yfinance), 거시 지표(FRED), 수급(투자자별·외국인·공매도·프로그램) |
| 시뮬레이션 | «이때 샀으면», 백테스트, 이벤트 리플레이 |
| 전략 | 전략 정의, 실행 ON/OFF, 전략 로그(왜 사고팔았나), 전략별 주문, 버전·승인 |
| 분석 에이전트 | 에이전트별 분석 결과를 저장·열람, 관심 종목·섹터 기반 분석 |
| 성과 분석 | 일별·누적 수익률, 거래 내역, 전략별 성과·승률·MDD, 세금 요약 |
| 실시간 반영 | 시세·주문 상태·손익을 화면에 즉시 반영 |

## 로드맵

| 단계 | 목표 | 내용 |
|---|---|---|
| 0 | 브로커 계정 연동 | 토스·KIS 계좌·계정 연동(WebSocket·REST: 인증, 계좌·잔고 조회, 시세) |
| 1 | 원장 확정 | 부분 체결·취소·홀드/해제 정합성, KIS 모의 원장 대사 |
| 2 | 시뮬레이션 | «이때 샀으면», 백테스트 결과 조회 |
| 3 | 전략 | 전략 정의·ON/OFF·로그·전략별 주문, 기본 전략(이동평균 돌파), 위험 성향 프로필 |
| 4 | 분석 에이전트 1차 | 저장·열람 틀, 관심 종목·섹터, 뉴스·공시, 차트 분석·수급 품질 개선 |
| 5 | AI 전략 | 전략 생성·검증·반박·승인, 여러 AI 비교, MiroFish, 복제 계좌 전략 비교 |
| 6 | 확장 | TimesFM·Kronos, 폴리마켓, 논문·특허·커뮤니티, 연관관계 추론 |
| 마지막 | 실전 주문 | KIS·토스 실계좌 주문 실행 |

실제 돈이 들어가는 연동은 모의 원장의 정합성이 검증된 뒤에만 진행합니다.

## 아키텍처

```text
KIS·Upbit WebSocket/REST ─▶ collector-api ─▶ Redis(최신가, Pub/Sub) ─▶ trading-api(체결 엔진·원장)
                                  └─▶ PostgreSQL(히스토리)
quant-worker: 일봉 수집·백테스트·분석 에이전트·AI 전략
trading-web: 운영 화면
```

| 서비스 | 역할 | 기술 |
|---|---|---|
| `backend/trading-api` | 주문·체결·계좌·포지션·정산·전략 실행 | Kotlin, Spring Boot 3, JPA, PostgreSQL, Redis |
| `backend/collector-api` | 실시간 시세 수집, Redis 발행, 히스토리 적재 | Kotlin, Spring Boot 3, Redis |
| `quant-worker` | 일봉 수집, 백테스트, 분석 에이전트, AI 전략 | Python 3.11, FastAPI, SQLAlchemy, LangChain·LangGraph |
| `frontend/trading-web` | 운영 화면 | React, TypeScript, Vite, Tailwind, shadcn/ui |
