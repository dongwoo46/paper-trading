## 3. 기능 목적

- [스펙] 사용자/액터: paper-trading 운영자.
- [스펙] 사용자 문제: 기능이 11개 평면 메뉴에 섞여 있고, 화면마다 제목·표면·밀도가 달라 작업 위치를 빠르게 파악하기 어렵다.
- [스펙] 비즈니스 의도: 현재 라이트 shadcn 기반을 유지하면서 전문적인 트레이딩 워크스테이션으로 시각 체계와 정보 구조를 정돈한다.
- [보강] 완성 모습: 운영자가 업무 그룹을 따라 이동하고, 각 화면에서 제목·설명·핵심 행동의 위치를 즉시 예측하며, 홈에서 실제 기능으로 바로 진입한다.
- **안 만드는 것 (non-goal):** [보강] 다크 테마, 신규 API·가짜 KPI, 거래 계산 변경, 인증·권한 체계 신설, 차트 엔진 재설계.
