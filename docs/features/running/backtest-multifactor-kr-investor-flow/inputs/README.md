# 기획 입력 (inputs)

이 폴더에 **기능의 입력 자료**를 넣으세요 — planner·구현 스킬이 *여기를 보고* 동작합니다:

- 화면정의서 · 기능정의서 · 정책 문서 (`.md`/`.pdf`/`.txt`)
- **Figma 스크린샷**(`.png`/`.jpg`) — 난잡 Figma 면 `screen-from-image` 가 렌더 결과만 계약으로.
- 기존 API/도메인 맥락(있으면).

> planner(`feature-planning`)는 이 자료로 feature-spec 을 보강하고, 빈틈은 open-questions(ASK)로 올립니다.
> 입력이 ~60%만 채워져도 됩니다 — 빈틈을 *추측이 아니라 플래그*로 드러내는 게 핵심.
