### FLAG-01 — API 없는 화면의 범위·순서

| 방법 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A ⭐ | 2단계로 나눈다. 1단계 = API 가 있는 화면(홈 일부·계좌·포지션·포트폴리오·주문창·거래 내역·차트·수집 현황 일부) 실데이터 연결. 2단계 = 전략·비교·AI 연구·사건 분석·백테스트 리포트는 «API 계약(타입)과 가상 데이터 어댑터»로 화면만 완성하고, 백엔드가 생기면 어댑터를 교체 | 바로 쓸 수 있는 화면이 먼저 나온다. 계약을 먼저 적으면 백엔드 설계의 입력이 된다 | 2단계 화면은 가상 데이터라 «운영 화면처럼 보이는 가짜» 위험. 어댑터 표기 필요 |
