## 1. 한 줄 요약
`isTest` 가 확장자와 무관하게 `test/`·`tests/` 경로 전체를 시험으로 쳐, 그 폴더의 문서(.md) 이동·편집이 시험 변경으로 판정됐다.

## 2. 환경 (provenance)
- 레포 / 컨텍스트: paper-trading 규칙 이사(test 폴더 문서 archive 이동)
- devkit 버전: 1.2.0
- gitSha: 93a1f8f 근처
- 모드 / tier: 미상
- OS / 런타임: macOS

## 3. 재현 절차 (결정적으로)
1. `src/test/README.md` 같은 문서를 바꾸거나 옮긴다.
2. test-gate 판정을 받는다.
3. 문서가 시험 파일로 분류된다.

## 4. 기대 동작 vs 실제 동작
- 기대: 코드 확장자(.js·.ts·.py 등)만 시험 파일로 침.
- 실제: .md 도 시험으로 침. 원문 그대로 이름 바꿈(R100) 커밋과 다음 커밋 정리로 나눠 우회했다.

## 5. 영향 (impact)
- 무엇이 깨지나: 시험 폴더 문서 작업이 시험 게이트에 거짓으로 걸림. 반대로 «시험을 바꿨다» 신호가 문서 변경으로 채워질 수 있음.
- 심각도: low

## 6. 근본 원인 (추정 — 딱지)
`코드` tools/test-gate.js:28-30 `isTest` 의 둘째 식 `/(^|\/)(tests?|__tests__)\//` 에 확장자 조건이 없다. 첫째·셋째 식은 파일 이름 꼴을 본다. 426행 주석도 이 넓음을 알고 다른 자리에서 좁힌다.
